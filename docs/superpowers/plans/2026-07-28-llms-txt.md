# ADMIRATE `llms.txt` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a factual, specification-shaped AI resource guide at `https://admirate.in/llms.txt` that stays synchronized with ADMIRATE's public content registries.

**Architecture:** A pure JavaScript catalog/Markdown module will own resource ordering and serialization, following the existing testable sitemap pattern. A static Next.js route will supply ADMIRATE's current metadata, services, posts, legal documents, contact links, and curated service summaries, then return the generated Markdown with the correct content type.

**Tech Stack:** Next.js 16 App Router, TypeScript, ECMAScript modules, Node's built-in test runner.

## Global Constraints

- Serve the document at exactly `/llms.txt`; do not add the non-conventional `/llm.txt` alias.
- Use absolute canonical URLs rooted at `https://admirate.in` through `SITE.url`.
- Include primary pages, all registered services, all journal articles, contact/profile links, legal pages, and the HTML sitemap.
- Exclude `/dashboard`, `/dashboard/login`, `/api/*`, and every other operational route.
- Keep descriptions factual and based on existing public site copy; do not add ranking guarantees, keyword stuffing, or hidden model instructions.
- Return `Content-Type: text/markdown; charset=utf-8` from a statically generated route.
- Do not add `llms-full.txt`, edit `robots.txt` or the XML sitemap, add visible navigation links, or introduce dependencies.

Create `src/components/llms/catalog.mjs` with:

```js
const compact = (value) => String(value ?? "").replace(/\s+/g, " ").trim();

const label = (value) => compact(value).replace(/([\\\[\]])/g, "\\$1");

const originUrl = (origin, path = "") =>
  `${String(origin).replace(/\/$/, "")}${path}`;

const resource = (labelValue, href, description) => ({
  label: compact(labelValue),
  href: compact(href),
  description: compact(description),
});

export function buildLlmsSections({
  origin,
  homeDescription,
  services,
  serviceDescriptions,
  posts,
  legalDocs,
  contacts,
}) {
  return [
    {
      title: "Primary pages",
      links: [
        resource("Home", originUrl(origin), homeDescription),
        resource(
          "Services",
          originUrl(origin, "/services"),
          "ADMIRATE's design, marketing, digital, video, and brand services.",
        ),
        resource(
          "Journal",
          originUrl(origin, "/blogs"),
          "Practical writing about branding, design, websites, and marketing.",
        ),
        resource(
          "Start a Project",
          originUrl(origin, "/start-project"),
          "Share a project brief with ADMIRATE.",
        ),
      ],
    },
    {
      title: "Services",
      links: services.map(({ slug, label: serviceLabel }) =>
        resource(
          serviceLabel,
          originUrl(origin, `/services/${slug}`),
          serviceDescriptions[slug] ?? `${serviceLabel} services from ADMIRATE.`,
        ),
      ),
    },
    {
      title: "Journal",
      links: posts.map(({ slug, title, excerpt }) =>
        resource(title, originUrl(origin, `/blogs/${slug}`), excerpt),
      ),
    },
    { title: "Contact and profiles", links: contacts.map((item) => resource(item.label, item.href, item.description)) },
    {
      title: "Legal and site",
      links: [
        ...legalDocs.map(({ slug, title, description }) =>
          resource(title, originUrl(origin, `/${slug}`), description),
        ),
        resource(
          "Sitemap",
          originUrl(origin, "/sitemap"),
          "Directory of ADMIRATE's public pages.",
        ),
      ],
    },
  ];
}

export function renderLlmsTxt({ name, summary, overview, sections }) {
  const lines = [`# ${compact(name)}`, "", `> ${compact(summary)}`, "", compact(overview)];

  for (const section of sections) {
    lines.push("", `## ${compact(section.title)}`, "");
    for (const link of section.links) {
      lines.push(`- [${label(link.label)}](${link.href}): ${compact(link.description)}`);
    }
  }

  return `${lines.join("\n")}\n`;
}
```
